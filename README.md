# Abubakar Portfolio Redesign

A responsive, recruiter-focused portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Preview locally

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **Open with Live Server**.

You can also double-click `index.html`, although Live Server provides the most accurate preview.

## Publish to GitHub Pages

Replace the files in the `Abubakar-856.github.io` repository with these files, then commit and push:

```bash
git add .
git commit -m "Redesign portfolio and add SQL projects"
git push
```
